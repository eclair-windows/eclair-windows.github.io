Definition

What is Eclair?

Eclair is a full Lightning Network node implementation written in Scala and maintained by ACINQ. It runs on the Java Virtual Machine, connects to a Bitcoin Core backend, and implements the BOLT (Basis of Lightning Technology) specifications so it can open payment channels, route payments, and interoperate with other Lightning implementations such as LND and Core Lightning.

Eclair is aimed at operators who need a dependable, scalable routing node rather than a desktop wallet. The same engine underpins ACINQ’s own infrastructure and the technology behind the Phoenix wallet.

Why operators pick it

Key characteristics

01 Built for scale

Eclair’s design targets large routing nodes with many channels, favouring throughput and reliability over a bundled GUI.

02 BOLT-compliant

It follows the open Lightning specifications, so it interoperates cleanly with other spec-compliant nodes across the network.

03 API-first

A JSON-RPC API and the eclair-cli tool let you script node operations, integrate services, and automate channel management.
