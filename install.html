How to install Eclair

The requirements and the shape of a typical setup. Downloads go straight to ACINQ’s official releases.

Download Eclair

Get the latest signed release directly from ACINQ on GitHub.

Official releases ↗

Only download Eclair from the official ACINQ repository. This guide is a community overview; the official README is the source of truth for exact versions and commands.

Requirements

ComponentNotes
JDKA recent 64-bit Java Development Kit. Eclair targets a modern LTS release — confirm the exact required version in the release notes before installing.
Bitcoin CoreA fully synced bitcoind node acts as Eclair’s backend. Certain options must be enabled; see the official docs.
Disk & RAMEnough for a synced Bitcoin Core node plus Eclair’s own database and JVM headroom.
NetworkingA reachable node needs its Lightning port open; many operators also run over Tor.

Typical setup

  1. Install a JDK

    Install a supported 64-bit JDK and confirm it’s on your PATH:

    $ java -version

  2. Run and sync Bitcoin Core

    Install Bitcoin Core, enable the options Eclair needs (RPC access, transaction indexing, ZeroMQ notifications where required), and let it fully sync before continuing.

  3. Download the official release

    Grab the latest release artifact from ACINQ’s GitHub releases. Verify the download against the checksums/signatures ACINQ publishes.

  4. Create eclair.conf

    Add your configuration file (typically under ~/.eclair/eclair.conf) pointing Eclair at your Bitcoin Core node and setting your chain and node options:

    # minimal example — check the docs for current keys
eclair.chain = "mainnet"
eclair.bitcoind.rpcuser = "your_rpc_user"
eclair.bitcoind.rpcpassword = "your_rpc_password"

  5. Start the node and use eclair-cli

    Launch the daemon, then drive it through the CLI:

    $ eclair-cli getinfo
$ eclair-cli connect --uri=<node_uri>
$ eclair-cli open --nodeId=<id> --fundingSatoshis=<amount>

Commands, config keys and required versions evolve. Treat this page as orientation and follow the official README for exact, current instructions.
